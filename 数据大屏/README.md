# DLDS-532 工业网络智能控制与维护可视化系统

Windows 桌面端（WPF / .NET 8）工业数据监控大屏，只读读取西门子 S7-1200 的 DB120，1920×1080 深蓝工业风。

> 本软件**只读**：不写 DB120、不改运行模式、不触发开始/复位信号、不操作伺服与气缸。

## 快速开始

```bat
dotnet run --project src\DLDS532.App
```

或直接运行 `src\DLDS532.App\bin\Debug\net8.0-windows\DLDS532.exe`。

- `F11` 全屏 / `Esc` 退出全屏
- 出图：`DLDS532.exe --shot out.png --page 0`（0 总览 / 1 通信 / 2 单元数据 / 5 设置）

## 自测

```bat
dotnet run --project tests\DLDS532.SmokeTests
```

56 项断言：映射表结构、现场黄金样本解码、模拟帧源、采集与断线重连、运行事件、冻结判定。

## 打包

```bat
installer\build-installer.bat
```

自动完成自包含发布 + Inno Setup 编译，产出 `dist\DLDS-532-0.5.0-win-x64-setup.exe`（约 49 MB，目标机**无需安装 .NET**）。
安装向导支持自定义目录、开始菜单/桌面快捷方式、开机自启；卸载会清除程序、快捷方式、注册表项与运行数据。详见 `docs/09-打包与安装说明.md`。

```
installer/                  Inno Setup 安装脚本、中文语言包、一键构建脚本

```
