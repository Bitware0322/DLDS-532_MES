# 打包与安装说明（阶段六）

- 日期：2026-11-24
- 产物：`dist\DLDS532-0.5.0-win-x64-setup.exe`
- 目标机要求：Windows 10 1607+ / 11，x64，**无需预先安装 .NET**

---

## 一、一键构建

```bat
installer\build-installer.bat
```

两步：

1. `dotnet publish -c Release -r win-x64 --self-contained true -o dist\win-x64`
   产出 266 个文件约 162 MB，含 `coreclr.dll` / `hostfxr.dll`，因此目标机不需要装 .NET 运行时。
2. `ISCC.exe installer\DLDS532.iss` 用 Inno Setup 6 压成单个 exe。

**前置依赖**：Inno Setup 6（本机已装 6.7.3，位于 `%LOCALAPPDATA%\Programs\Inno Setup 6\`）

```bat
winget install JRSoftware.InnoSetup
```

> 沙箱里 MSBuild 会静默失败，脚本里已带 `-m:1 -nodeReuse:false -p:UseSharedCompilation=false` 三个绕过参数，别删。

## 二、安装向导流程

标准 Inno Setup 向导，简体中文界面（官方未内置中文，语言包在 `installer\languages\ChineseSimplified.isl`，只翻译向导可见消息，其余自动回退英文）：

| 步骤 | 内容 |
|---|---|
| 1 | 欢迎页 |
| 2 | **选择安装位置** —— 默认 `C:\Program Files\DLDS-532`（提权）或 `%LOCALAPPDATA%\Programs\DLDS-532`（不提权），**可自由修改**，带「浏览」与磁盘占用提示 |
| 3 | **选择附加任务** —— 桌面快捷方式、开始菜单快捷方式、**开机自动启动** |
| 4 | 准备安装（回显安装位置与所选任务） |
| 5 | 安装进度 |
| 6 | 完成页，可勾选立即运行 |

### 2.1 权限模型

`PrivilegesRequired=lowest` + `PrivilegesRequiredOverridesAllowed=dialog`：

- 默认**不需要管理员**，装到当前用户目录 —— 现场工控机常常拿不到管理员密码；
- 向导里可选「为所有用户安装」，勾选后才弹 UAC，装到 `Program Files`；
- 注册表用 `HKA` 根（提权写 HKLM、不提权写 HKCU），两种模式都能正确记录与清理。

### 2.2 附加任务说明

| 任务 | 默认 | 作用 |
|---|---|---|
| 创建桌面快捷方式 | 勾选 | `{autodesktop}\DLDS-532.lnk` |
| 创建开始菜单快捷方式 | 勾选 | 开始菜单 `DLDS-532` 文件夹，含程序与「卸载 DLDS-532」两项 |
| 开机自动启动 | **不勾选** | 写 `Software\Microsoft\Windows\CurrentVersion\Run\DLDS-532` |

开机自启写的是**注册表 Run 键**（不是启动文件夹），卸载时会自动删除该值。

## 三、安装程序写入的内容

| 类别 | 位置 |
|---|---|
| 程序文件 | `{app}`，即用户选择的安装目录 |
| 桌面快捷方式 | `{autodesktop}\DLDS-532.lnk` |
| 开始菜单 | `{autoprograms}\DLDS-532\`（程序 + 卸载） |
| 应用注册项 | `HKA\Software\DLDS-532`：`InstallPath` / `Version` / `DataDir` |
| 自启项 | `HKA\...\CurrentVersion\Run\DLDS-532`（仅勾选时） |
| 卸载入口 | `HKA\...\Uninstall\{6F1B7C2A-...}_is1`（Inno 自动维护） |

运行期数据不在安装目录，而在 `%LOCALAPPDATA%\DLDS532\`（`settings.json`、`run-events.jsonl`）。

## 四、卸载

三种入口：开始菜单「卸载 DLDS-532」/ 控制面板「应用和功能」/ 安装目录 `unins000.exe`。

清理范围：

- 安装目录全部文件，最后删除目录本身（`dirifempty`）；
- `HKA\Software\DLDS-532` 整个键（`uninsdeletekey`）；
- 自启值（`uninsdeletevalue`）；
- 卸载注册项（Inno 自动移除）；
- **`%LOCALAPPDATA%\DLDS532\` 整个目录**（`[UninstallDelete] filesandordirs`）—— 设置与事件日志一并清除。

> ⚠️ 最后一条意味着**卸载会丢掉历史事件日志**。如果现场需要保留台账，卸载前先把 `%LOCALAPPDATA%\DLDS532\run-events.jsonl` 拷出来。

### 5.1 一个环境坑（只影响本机验证，不影响交付物）

在本机**直接从 `D:\GthubPushRes\产线数据大屏开发\dist\` 运行安装包**会返回 `exit=1` 且不产生日志；**把同一个 exe 复制到 `%TEMP%`（英文或中文目录都试过）就能正常安装**。

已排除：压缩算法（zip / lzma2 都一样）、安装包体积（2 MB 的探针包同样失败）、`[Setup]` 各指令（逐组二分均正常）、Inno 不支持中文路径（`%TEMP%\测试中文目录\` 下运行成功）。

结论：是该目录的沙箱执行策略导致的，与安装包本身无关。现场交付的安装包不受影响，但**在本机做回归验证时请先把安装包复制到临时目录再运行**。

## 六、注意事项

1. **`AppId` 一旦发布不可再改**（`{{6F1B7C2A-7E64-4C3B-9A1E-3D5A0C8B4E21}`）。改了会被 Windows 当成另一个软件，导致新旧两份并存、卸载残留。
2. 版本号在 `installer\DLDS532.iss` 的 `#define AppVersion` 与 `src\DLDS532.App\DLDS532.App.csproj` 的 `<Version>` 两处，发版时同步改。
3. 覆盖安装用 `ignoreversion recursesubdirs`，不会删除用户改过的 `config\db120.mapping.json`（如果现场改过）。
4. 安装包 **49 MB**（162 MB 产物用 lzma2/max 压缩后），安装后占用约 170 MB。
5. 程序自身带 `--shot` 等命令行参数，自启时不带参数即正常全屏大屏模式。
