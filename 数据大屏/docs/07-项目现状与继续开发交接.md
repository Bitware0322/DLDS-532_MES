## 一、项目是什么

Windows 桌面端（WPF / .NET 8）工业数据监控大屏，**只读**读取西门子 S7-1214C 的 `DB120（0.MES通讯数据，190 字节）`，1920×1080 深蓝工业风，含四个页面（总览 / 通信管理 / 单元数据 / 系统设置）。

四条贯穿全项目的硬约束（后续开发不要破坏）：

1. **绝不写 PLC**：没有写 DB、改模式、触发开始/复位、操作伺服气缸的任何代码路径。`IPlcFrameSource` 只暴露 `Read`；`S7FrameSource` 里连 `Write*` 都不出现。
2. **地址只来自配置**：代码中不写死任何 DB120 偏移，全部读 `config/db120.mapping.json`（`Db120Mapping.Validate` 还会强制校验 `rw == "R"`）。
3. **不造假数据**：无数据一律显示 `--`，不补 0；模拟数据源必须被界面标注「模拟数据」；事件只在真实跃变时记录。
4. **采集与界面解耦**：PLC 读取永不在 UI 线程；界面按固定节拍取「最新快照」，不接收事件风暴。

## 五、DB120 数据契约（最重要）

`config/db120.mapping.json` 是唯一事实来源，结构：

```json
{
  "schemaVersion": "1.0", "dbNumber": 120, "blockName": "0.MES通讯数据",
  "totalBytes": 190, "byteOrder": "BigEndian",
  "layout": { "bool": "bit", "int": 2, "dint": 2, "real": 2, "struct": 2, "arrayOfBool": "byte-aligned start" },
  "verification": { "plc": "192.168.40.115", "maxReadableBytes": 190, "probeResult": "190 OK / 191 FAIL(0x05)", ... },
  "fields": [ { "path", "type", "offset", "bit", "bytes", "elements", "id", "label", "unit", "decimals", "show", "group", "rw", "note" } ]
}
```

- 字段总数 **79**（其中 **61** 个有语义 `id`，18 个是各站 `保留_1..保留_6` 的调试位，`id` 为空、`show=false`）。
- 四个连续区段：一站 `0`（58B）、二站 `58`（46B）、三站 `104`（60B）、订单区 `164`（26B），合计 190。
- **关键布局结论**：S7-1200 非优化块中 `Real/DInt` 只做 **2 字节对齐**（不是 4）。按 4 字节推导会让心跳落在 16、二三站与订单区全部错位、总长变 198。这一条已被现场字节与黄金样本双重验证。
- 心跳是 Int16 自增计数器，会回绕成负数；界面统一按 `& 0xFFFF` 无符号显示。
- 三站仓位 `s3.slots` 是 **Bool[9] 跨字节数组**（`122.0`~`123.0`，数组[0]=A … 数组[8]=I；121 是对齐填充）。**界面按 A 在右下角逆序摆放**（I H G / F E D / C B A），只影响显示位置。二站料仓两位是相邻的 `82.0/82.1`。
- 读取策略：一次 `ReadBytes(DB120, 0, 190)`，不做多次小读。

### 9.1 本机（DSH 沙箱）环境坑，已解决但要记住

1. **MSBuild 静默失败**：沙箱里 MSBuild 的节点复用 / 共享编译要靠命名管道，会被拒，表现为「生成失败，0 个警告，0 个错误」。加参数即可绕过：
   `dotnet build DLDS532.sln -c Release -m:1 -nodeReuse:false -p:UseSharedCompilation=false`
   （切换成完全权限后不需要这些参数。）
2. **`tests\DLDS532.SmokeTests` 曾整棵子树不可写**（任何新建文件都被 Windows 拒绝），导致测试工程编译失败。根因是该目录缺少与其它目录一致的「低完整性」标记，不是代码问题。已于 2026-11-24 用
   `icacls "…\tests\DLDS532.SmokeTests" /setintegritylevel "(OI)(CI)Low" /T /C /Q`
   修复（82 个对象）。如需回滚：同一条命令把 `Low` 换成 `Medium`。诊断记录留在 `.workbuddy\acl-recovery\`。
3. **PowerShell 5.1 读 UTF-8 无 BOM 文件会当 ANSI**：直接 `Get-Content x.json | ConvertFrom-Json` 会乱码并报「传入的对象无效」。请用 `-Encoding UTF8` 或 `[System.IO.File]::ReadAllText($p,[Text.Encoding]::UTF8)`。C# 侧不受影响。
4. **exe 正在运行会导致 MSB3027**（文件被占用），编译前先结束 `DLDS532` 进程。
5. 出图是异步的：`DLDS532.exe --shot` 启动后约 8.5 秒才落盘并自动退出，脚本里别用同步等待。
