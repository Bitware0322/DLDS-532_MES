# UI 第二轮优化说明（SCADA 视觉重构）

- 日期：2026-11-23
- 版本：v0.3.0（阶段二 UI R2）
- 范围：**只改视觉与交互层**。PLC 通信、DB120 映射解码、采集与重连、趋势缓冲、报警口径一律未动
- 验收：Release 编译 0 警告 0 错误；37 项冒烟测试全部通过（含现场黄金样本解码、断线重连）

---

## 一、先诊断：第一版到底哪里不舒服

| 问题 | 具体表现 | 根因 |
|---|---|---|
| 满屏蓝 | 所有数值都是同一个青色，状态灯与数字同色 | 色板只有一个强调色，颜色没有语义分工 |
| 信息密度过高 | 左栏一屏 16 个指标，字号接近，找不到重点 | 每个字段平铺，没有主次层级 |
| 没有留白 | 面板内边距 12px、模块间 12px，边框紧贴文字 | 间距与圆角没成体系 |
| 装饰压过内容 | 四角科技边框 + 渐变标题条 + 背景网格 | 装饰元素过多，与"专业 SCADA"背道而驰 |
| 字号扁平 | 标题 14 / 数据 17 / 标签 12，差距不足 5px | 未建立字号阶梯 |
| 图表拥挤 | 7 条曲线挤一个纵轴，量纲不同（mm/°/颗/g） | 强行共轴，坐标没有物理意义 |
| 表格密 | 行高 46、带竖分割线、状态纯文字 | 缺少行距与状态标签 |

## 二、改了什么（按你的六步）

### 1. 配色：从"单色蓝"到"功能色"

严格按你给的表落地，并把语义写进代码（`Palette.cs` 注释即规范）：

| 用途 | 颜色 | 用在哪 |
|---|---|---|
| 主背景 / 模块 / 次级 | `#101820` / `#182632` / `#203442` | 窗口、卡片、卡片内小卡 |
| 边框 | `#344956` / `#2A3E4C` | 卡片描边、分隔线 |
| 主文字 / 次级 | `#E6EDF3` / `#9BAEBB` | 数值 / 标签 |
| 品牌蓝 | `#36A9E1` | 通信、位置、加工中、选中态 |
| 运行绿 | `#36C98F` | 在线、完成、合格、仓位有料、合格率 |
| 提示橙 | `#F2B45B` | 等待、待接收、10mm 灌注 |
| 故障红 | `#EF6262` | 故障、不合格、Y 轴 |
| 数据紫 | `#A78BFA` | 8mm 灌注（工艺量） |
| 辅助青 | `#42C6C5` | 实时测量值（深度检测） |

关键动作：**`Metric` 的默认数值颜色从蓝色改成灰白**，只有明确赋义的指标才上色。这一步让整屏"蓝味"立刻降下来。

### 2. 布局：27 / 45 / 28

| 项 | 第一版 | 现在 |
|---|---|---|
| 顶栏 | 72px | **60px** |
| 三栏宽度 | 500 / 864 / 500 | **484 / 802 / 498**（27% / 45% / 28%） |
| 模块间距 | 12px | **16px** |
| 卡片内边距 | 12px | **16 / 14px** |
| 圆角 | 3px | **8px**（小卡 6px） |
| 装饰 | 四角括号 + 标题渐变条 + 背景网格 | **全部移除**，改为 1px 描边 + 轻微投影 |

### 3. 左侧：先看状态，再看工艺

- **数据管理**卡只留 4 类信息：数据管理 PLC 状态、DB120 状态、延迟/周期/帧长（次级小字）、三个单元在线灯。参数细节移到通信管理页。
- **自动供料 / 智能分拣**改成 **2 列 × 3 行小卡**：订单 ID、深度检测用 26px 加粗 + 青色，其余 18～20px 灰白。
- 扫码、完成、已接收、工作时间全部下沉到模块底部状态栏，不再与主数据抢注意力。
- 料仓状态改为 **圆点 + 文字**（绿=有钢珠 / 灰=无钢珠）。
- 每张卡右上角保留 3 个状态标签（模式 / 忙碌 / 故障），故障时标签圆灯**缓慢呼吸**。

### 4. 中央：订单表 + 趋势

- 表格行高 46 → **50**，去掉竖分割线，订单号 17px 加粗，状态改成**彩色标签**（加工中蓝 / 完成绿 / 等待橙 / 故障红）。
- 表头右侧明确写"当前订单数据 · DB120 未提供历史订单"，底部注明状态推导规则 —— 不伪造记录。
- 趋势图：
  - 绘图区高度占卡片 70%，网格线亮度降到 `#1B2B36`，只留 4×4 条；
  - 坐标轴刻度改为 **1/2/2.5/5 × 10ⁿ 的整齐步长**（原来是 16.23 / 14.16 这种读不出来的值）；
  - **按量纲分组**：一站深度 / 三站坐标 / 转盘角度 / 灌注数量 / 三站称重，组内共用一条纵轴，绝不混量纲；
  - 组内曲线可单独开关，选中一条即为"单变量放大"；
  - 图例 = 彩色短线 + 名称 + 当前值；底部显示采样周期、入图周期、数据点数。

### 5. 右侧：位置 / 统计 / 仓位

- **设备位置监控**：4 个大数字，颜色区分轴（转盘蓝、机械手青、X 黄、Y 红），并按你的要求保留"DB120 无轴速度字段，速度未做推算"。
- **订单加工**：6 个数字卡 + 合格率进度条（绿），统计口径不变（合格/不合格直接取三站计数，已完成来自软件侧订单切换记录）。
- **智能仓储**：仓位卡放大（22px 字母 + 状态灯），有料绿框深底、空仓灰框暗底，右上角显示占用比；顶部 4 个指标（入站/入库/称重/合格状态）。

### 6. 字体与层次

| 层级 | 字号 | 用法 |
|---|---|---|
| 系统标题 | 22 | 顶栏 |
| 模块标题 | 16 SemiBold | 卡片头 |
| 关键数据 | 26 SemiBold | 订单 ID、深度值 |
| 普通数据 | 18～21 | 其余指标 |
| 数据名称 | 12.5 | 指标标签 |
| 辅助信息 | 10.5 | 采样说明、来源注释 |

字族统一 `Microsoft YaHei UI`（中文）/ `Segoe UI`（数字），仅关键数字加粗。

## 三、交互

| 需求 | 实现 |
|---|---|
| 悬停看变量名与来源 | 每个指标卡 ToolTip 写明 `一站数据.深度检测值 · DB120 偏移 28.0 · REAL` |
| 点击单元卡片进详情 | 三张单元卡支持左键点击 → 跳到「单元数据」页并**高亮对应区域 4 秒** |
| 保留左侧导航 | 保留，样式改为圆角选中块，未实现页仍置灰标注阶段 |
| 模拟数据标识 | 顶栏常驻橙色「模拟数据」标签 |
| 断线不装实时 | 断线时数值转灰、状态灯红、顶部显示「通信中断」，并保留最后一次有效数据且标注过期 |
| 状态变化轻动画 | 仅故障标签呼吸；**不做数值闪烁**（数据 2Hz 刷新，闪烁会变成干扰，违背你"不要频繁闪烁"的要求） |

## 六、还可以继续打磨的点（等你定）

1. **动画**：目前只有故障呼吸。若想要"数值刷新微光"，建议只对 3～5 个关键指标做 300ms 淡入，且可关闭。
2. **趋势**：可加"极值/均值"辅助线与游标读数（鼠标悬停显示某时刻数值）。
3. **仓位**：可加点击查看仓位明细（当前 DB120 只有占用位，没有仓位内产品信息）。
4. **主题**：若要接现场大屏偏亮的观看环境，可再出一套浅色版本（结构不变，只换色板）。
