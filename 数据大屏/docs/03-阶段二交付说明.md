## 一、怎么跑起来

### 1. 开发运行

```bat
cd /d D:\GthubPushRes\产线数据大屏开发
dotnet run --project src\DLDS532.App
```

### 2. 直接运行已编译程序

```bat
cd src\DLDS532.App\bin\Debug\net8.0-windows
DLDS532.exe
```

程序目录下必须有 `config\db120.mapping.json`（编译时自动复制，改映射表不用重新编译）。

### 3. 快捷键

| 按键 | 作用 |
|---|---|
| `F11` | 进入无边框全屏（大屏模式，隐藏系统标题栏） |
| `Esc` | 退出全屏 |

窗口默认 1680×945，可任意缩放/最大化；内部固定 1920×1080 设计画布，按 `Viewbox` 等比缩放，不会变形。

### 4. 出图模式（回归检查用）

```bat
DLDS532.exe --shot out.png --page 0    :: 0 总览 / 1 通信 / 2 单元数据 / 5 设置
```

会以 1920×1080 离屏渲染一张 PNG 后自动退出，用于版本对比，不影响正常启动。

### 关键设计：模拟源伪造的是「字节」，不是「界面数值」

```
SimulatedFrameSource  →  byte[190]（按 DB120 真实偏移写大端）
        ↓
Db120Decoder（读 config/db120.mapping.json）
        ↓
PlcSnapshot（强类型、不可变）
        ↓
DashboardViewModel（格式化/配色/统计）
        ↓
XAML 绑定
```

所以阶段二已经验证了「偏移 → 解码 → 单位 → 显示」整条链路。阶段三只需把 `SimulatedFrameSource` 换成 S7 帧源（同样返回 `byte[190]`），**界面、解码、趋势、报警代码一行都不用改**。

37 项全部通过，分四组：

- **映射表**：190 字节、78 字段、全部只读

## 七、阶段三开始前需要你确认/配合

1. **PLC 现在是 STOP**：阶段三要验证 REAL/INT/BOOL 与 TIA 一致，最好让 CPU 处于 RUN 且产线能动一下，否则只能验证静态值。
2. **TIA 偏移核对 5 项**（见 `docs/01` 第七节），特别是 `10.0` 一站步骤、`58.0/104.0` 二站/三站起点、`121.0` 仓位数组、`82.1` 10mm 料仓。
3. S7 库选择：默认用 `S7netplus`（纯托管）；若现场会话异常，切 `Sharp7` 或 P/Invoke `snap7.dll`（已用 snap7 验证过通路）。需要我准备离线 NuGet 包的话，请告知内网 NuGet 源情况。
